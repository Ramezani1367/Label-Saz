تولید انبوه تصویر از قالب فتوشاپ

یک فایل فتوشاپ + یک فایل اکسل → برای هر ردیف یک خروجی (PNG/JPG/WEBP/PDF)، با نام‌گذاری دلخواه و پوشه‌ی جدا برای هر شیت.

Python 3.9+ رابط HTML فارسی و راست‌چین نسخه‌ی ویندوزی بدون پنجره‌ی CMD MIT License

این برنامه چه می‌کند؟

برنامه‌ای کاملاً محلی (بدون اینترنت) برای کارت ویزیت، برچسب محصول، سربرگ، گواهی و هر قالبی که متن‌هایش عوض می‌شود.

پلیس‌هولدر داخل متن

داخل متن لایه‌های فتوشاپ می‌نویسید {{نام و نام خانوادگی}} و برنامه با ستون هم‌نام در اکسل تطبیق می‌دهد.

چند شیت، چند قالب

هر شیت اکسل یک پوشه با همان نام می‌گیرد؛ برای هر شیت می‌توانید قالب PSD، ستون‌های نام فایل و بازه‌ی ردیف جدا بدهید.

خروجی PNG / JPG / WEBP

برای هر ردیف یک تصویر، با دقت دلخواه (تا ۳۰۰٪) و کیفیت لبه‌های قابل تنظیم.

خروجی PDF سه‌حالته

یکپارچه در هر پوشه، یکپارچه برای همه‌ی شیت‌ها، یا جدا برای هر ردیف — همراه با فهرست CSV.

فونت فارسی

شکل‌دهی صحیح فارسی/عربی با HarfBuzz؛ انتخاب فونت جانشین یا افزودن فایل فونت.

نسخه‌ی ویندوزی

ساخت exe بدون پنجره‌ی CMD و با آیکون، هم روی گیت‌هاب (Actions) و هم روی ویندوز خودتان.

خروجی PDF — هم یکپارچه، هم جدا جدا

در تب ۱ فرمت خروجی را PDF بگذارید و حالت دلخواه را انتخاب کنید.

اجرا و ساخت نسخه‌ی ویندوزی

همه‌ی راه‌ها بدون پنجره‌ی کنسول (CMD) اجرا می‌شوند و آیکون اختصاصی دارند.

۱) با گیت‌هاب (بدون نصب چیزی)

ریپازیتوری را push کنید؛ ورک‌فلو build-windows خودش exe را می‌سازد و در تب Actions → Artifacts می‌گذارد. با تگ v1.0.0 در Releases هم منتشر می‌شود.

۲) ساخت روی ویندوز خودتان

دوبار کلیک روی packaging/build_windows.bat → dist\PSD-Batch-Generator\PSD-Batch-Generator.exe

۳) اجرا از سورس بدون CMD

دوبار کلیک روی run_windows.bat؛ پنجره‌ی سیاه باز نمی‌شود و مرورگر خودکار می‌آید.
