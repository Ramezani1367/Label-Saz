# ساخت نسخه‌ی ویندوزی (exe) — بدون پنجره‌ی CMD، با آیکون

این سند سه راه برای رسیدن به «برنامه‌ی ویندوزی» توضیح می‌دهد:

| راه | برای چه کسی | نتیجه |
|---|---|---|
| **۱) گیت‌هاب (پیشنهادی)** | بدون نصب هیچ ابزاری | اکشن گیت‌هاب خودش exe را می‌سازد و برای دانلود می‌گذارد |
| **۲) ساخت روی ویندوز خودتان** | کسی که ویندوز دارد | `dist\PSD-Batch-Generator\PSD-Batch-Generator.exe` |
| **۳) اجرا از سورس بدون CMD** | کاربر معمولی با پایتون نصب‌شده | پنجره‌ی سیاه باز نمی‌شود؛ فقط رابط HTML باز می‌شود |

در همه‌ی راه‌ها: **آیکون برنامه** (`packaging/icon.ico`) روی فایل اجرایی و پنجره‌ی برنامه می‌نشیند و **پنجره‌ی کنسول (CMD) هیچ‌وقت باز نمی‌شود** (در فایل ساخت، `console=False`).

---

## ۱) ساخت با گیت‌هاب (بدون نصب هیچ‌چیز)

۱. این پوشه را در یک ریپازیتوری گیت‌هاب بگذارید (`git init` → `git add .` → `git commit` → `git push`).
۲. وارد تب **Actions** شوید. ورک‌فلو **build-windows** خودش با هر push اجرا می‌شود؛ اگر اجرا نشد، از دکمه‌ی **Run workflow** استفاده کنید.
۳. بعد از حدود ۳ تا ۵ دقیقه، پایین صفحه‌ی همان اجرا، بخش **Artifacts** ظاهر می‌شود:

   - `PSD-Batch-Generator-windows` → نسخه‌ی **ماژولار** (یک پوشه شامل exe + فایل‌های لازم) — **پیشنهادی**
   - `PSD-Batch-Generator-windows-onefile` → یک **تک‌فایل exe** (همه‌چیز داخل خودش؛ حجم بیشتر و اجرای اول کمی کندتر)

۴. فایل زیپ را دانلود و باز کنید؛ `PSD-Batch-Generator.exe` را دوبار کلیک کنید.

**ساخت نسخه‌ی رسمی (Release):** یک تگ بزنید و پوش کنید:

```bash
git tag v1.0.0
git push origin v1.0.0
```

همان لحظه فایل‌های زیپ در صفحه‌ی **Releases** ریپازیتوری برای همه قابل دانلود می‌شوند.

---

## ۲) ساخت روی ویندوز خودتان

پیش‌نیاز: [پایتون ۳.۹+](https://www.python.org/downloads/) با تیک **Add python.exe to PATH**.

روی فایل **`packaging\build_windows.bat`** دوبار کلیک کنید. این اسکریپت کتابخانه‌ها را نصب و بعد فایل اجرایی را می‌سازد؛ خروجی:

```
dist\PSD-Batch-Generator\PSD-Batch-Generator.exe      ← نسخه‌ی ماژولار (پیشنهادی)
```

یا دستی در ترمینال، داخل پوشه‌ی پروژه:

```bat
pip install -r requirements.txt
pip install pyinstaller
pyinstaller packaging\windows.spec --noconfirm --clean
```

برای ساخت **تک‌فایل**:

```bat
set PSD_BATCH_ONEFILE=1
pyinstaller packaging\windows.spec --noconfirm --clean
:: خروجی: dist\PSD-Batch-Generator.exe
```

### «ماژولار» یعنی چه؟

- نسخه‌ی پیش‌فرض (`--onedir`) یک پوشه است: فایل اجرایی + کتابخانه‌ها + پوشه‌های `web/`، `fonts/` و `samples/`.
  می‌توانید **بدون ساخت دوباره** فایل‌های رابط (`web/index.html`، `web/style.css`، `web/app.js`)، فونت‌ها یا نمونه‌ها را جایگزین کنید.
- کد برنامه هم ماژولار است: `server.py` (سرور و API)، `engine/` (موتور)، `web/` (رابط)، `windows_app.pyw` (ورود ویندوزی)، `packaging/` (ساخت exe).

---

## ۳) اجرا از سورس، بدون پنجره‌ی CMD

اگر پایتون نصب است و نمی‌خواهید exe بسازید:

- **`run_windows.bat`** را دوبار کلیک کنید؛ پنجره‌ی CMD بلافاصله بسته می‌شود و برنامه با `pythonw` بالا می‌آید.
- یا خودتان: `pythonw windows_app.pyw`

در این حالت هم یک پنجره‌ی کوچک کنترل نمایش داده می‌شود («باز کردن مرورگر» / «بستن برنامه») و متن خطاها (اگر پیش بیاید) در فایل `psd-batch.log` کنار برنامه ذخیره می‌شود.

> اگر `tkinter` نصب نباشد، برنامه بی‌صدا اجرا می‌شود و فقط مرورگر باز می‌شود؛ برای پایان کار، پروسه را ببندید.

---

## فایل‌های کاربر کجا ذخیره می‌شوند؟

| فایل | محل |
|---|---|
| `settings.json` (تنظیمات ذخیره‌شده) | کنار فایل اجرایی؛ اگر آن پوشه قابل‌نوشتن نبود: `%APPDATA%\PSD-Batch-Generator\` |
| `psd-batch.log` (لاگ اجرا) | همان‌جا |
| فونت‌های اضافه‌شده با دکمه‌ی «افزودن فونت» | پوشه‌ی `fonts` کنار برنامه |
| خروجی‌ها | پوشه‌ای که کاربر در تب ۱ انتخاب می‌کند |

---

## تغییر آیکون

۱. آیکون دلخواه را به‌صورت `.ico` چندسایزی آماده کنید (۱۶ تا ۲۵۶ پیکسل).
۲. جای فایل `packaging/icon.ico` بگذارید.
۳. (اختیاری) برای ساخت آیکون پیش‌فرض پروژه با کد: `python3 packaging/make_icon.py`
۴. دوباره بسازید (راه ۱ یا ۲).

---

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| ویندوز پیام **Windows protected your PC / SmartScreen** می‌دهد | چون فایل تازه و بدون امضای دیجیتال است؛ «More info» → «Run anyway». برای حذف دائمی باید فایل را با گواهی کد امضا (Code Signing) کنید. |
| آنتی‌ویروس به exe گیر می‌دهد | برای فایل‌های ساخته‌شده با PyInstaller پیش می‌آید؛ فایل را در آنتی‌ویروس سفید کنید یا نسخه‌ی `--onedir` را استفاده کنید. |
| «پورت آزاد نیست» | برنامه‌ی دیگری روی ۸۷۵۶ است؛ برنامه خودش ۱۲ پورت بعدی را امتحان می‌کند، ولی می‌توانید متغیر محیطی `PSD_BATCH_PORT` را هم تنظیم کنید. |
| برنامه باز می‌شود ولی صفحه‌ای نمی‌آید | فایل `psd-batch.log` کنار exe را ببینید؛ احتمالاً کتابخانه‌ای کم است یا آنتی‌ویروس فایلی را قرنطینه کرده است. |
| هنگام ساخت با گیت‌هاب خطای نصب کتابخانه | `requirements.txt` را چک کنید؛ اکشن روی `windows-latest` و پایتون ۳.۱۲ اجرا می‌شود. |
