# راهنمای تحویل به برنامه‌نویس (Handoff)

این پروژه یک **وب‌اپ محلی پایتون** است: یک فایل PSD و یک فایل اکسل می‌گیرد، متن لایه‌های
متنی را برای هر ردیف اکسل عوض می‌کند و خروجی (PNG/JPG/WEBP/PDF) می‌سازد. رابط کاربری HTML
است و با یک سرور پایتونی روی `127.0.0.1` سرو می‌شود. نسخه‌ی ویندوزی هم به‌صورت exe بدون
پنجره‌ی کنسول ساخته می‌شود (بخش `packaging/`).

---

## ۱) ساختار کد (نقشه‌ی ماژول‌ها)

```
run.py                  راه‌انداز عمومی (بررسی/نصب کتابخانه‌ها + اجرای سرور)
windows_app.pyw         ورود ویندوزی بدون کنسول: سرور در پس‌زمینه + پنجره‌ی کنترل کوچک
server.py               سرور HTTP استاندارد پایتون + همه‌ی APIها (تحلیل، پیش‌نمایش، اجرا، فونت، مرور پوشه)
engine/
  paths.py              مسیرها برای حالت عادی و حالت exe (PyInstaller/_MEIPASS)
  excelio.py            خواندن اکسل (همه‌ی شیت‌ها، عنوان ستون‌ها، مقدار هر سلول، نمونه‌سازی نام فایل)
  textdata.py           کار با لایه‌های متنی PSD: پلیس‌هولدرها، جهت متن، نوشتن مقدار جدید در لایه
  fonts.py              فهرست فونت‌های سیستم + انتخاب فونت جانشین برای فارسی/عربی
  render.py             رندر PSD → تصویر: متن فارسی (HarfBuzz)، افکت‌های لایه، ترکیب لایه‌ها
  runner.py             موتور دسته‌ای: نگاشت ستون‌ها، نام‌گذاری، PNG/JPG/WEBP/PDF، CSV، پیشرفت، توقف
web/                    رابط کاربری تب‌بندی‌شده (index.html، style.css، app.js) — فارسی و RTL
packaging/              آیکون + spec ساخت exe + اسکریپت ساخت ویندوزی + اطلاعات نسخه
tools/                  ساخت نمونه‌ها، ساخت پیش‌نمایش، اسکرین‌شات
tests/smoke_test.py     تست سلامت (اکسل → پلیس‌هولدر → رندر → خروجی کامل)
docs/                   همین راهنما + راهنمای ساخت ویندوزی + خلاصه‌ی انگلیسی
```

جریان داده: `web/app.js` → `/api/analyze` (سرور: `read_sheets` + `build_layer_index`) →
تب‌های ۱..۵ → `/api/preview` (`BatchRunner.render_single`) → `/api/start`
(`BatchRunner.run` در یک ترد، پیشرفت با `/api/status`) → فایل‌ها در پوشه‌ی مقصد.

## ۲) راه‌اندازی محیط توسعه

```bash
git clone <repo> && cd psd-batch-generator
python -m venv .venv && source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
python tools/make_sample.py       # ساخت نمونه‌ی اکسل و PSD
python tests/smoke_test.py        # تست سریع (باید همه ✅ باشند)
python run.py                     # اجرا + باز شدن مرورگر روی http://127.0.0.1:8756
```

تست‌های خودکار در گیت‌هاب: `.github/workflows/tests.yml` (اجرای `smoke_test.py` + بالا آمدن سرور).
ساخت exe: `.github/workflows/build-windows.yml` (دو آرتیفکت: پوشه‌ی ماژولار و تک‌فایل).

## ۳) نکته‌های فنی مهم

- **متن‌ها بازسازی می‌شوند، نه کپی.** موقعیت/اندازه/فونت/رنگ از خود لایه‌ی متنی فتوشاپ خوانده می‌شود
  (`render.py` → `parse_style`) و متن با Pillow + راقم (HarfBuzz) دوباره کشیده می‌شود. لهذا خروجی
  «رندر تقریبی» است؛ برای دقت میلی‌متری گزینه‌ی «ذخیره‌ی PSD اصلاح‌شده» وجود دارد.
- **افکت‌ها:** سایه‌ی بیرونی، خط دور (Stroke)، رنگ رویی و درخشش بیرونی بازسازی می‌شوند؛
  افکت‌های پیچیده (Bevel/Pattern/Gradient Overlay/Satin) رد می‌شوند و در گزارش هشدار می‌آیند.
- **سوپرسمپل:** رندر با ضریب `supersample` (پیش‌فرض ۲×) انجام و بعد کوچک می‌شود؛ برای چاپ ۳×.
- **حالت‌های PDF** (`runner.py` → `run()` و `_flush_pdf`): `each` (هر ردیف یک PDF)،
  `sheet` (در هر پوشه یک PDF یکپارچه)، `all` (یک PDF یکپارچه از همه‌ی شیت‌ها در ریشه‌ی مقصد).
  در حالت‌های یکپارچه، تیک `pdf_also_individual` فایل هر ردیف را هم جداگانه می‌سازد.
- **مسیرها:** هرگز مسیر را با `Path(__file__)` خام نسازید؛ از `engine.paths` استفاده کنید تا
  هم اجرای معمولی و هم نسخه‌ی exe درست کار کند.
- **فایل‌های کاربر** (`settings.json`، `psd-batch.log`) در `paths.app_dir()` نوشته می‌شوند،
  نه داخل پوشه‌ی نصب.

## ۴) کارهایی که می‌شود جلوتر برد (بک‌لاگ پیشنهادی)

1. **دقت کامل فتوشاپ:** جای رندر با Pillow، اجرای فتوشاپ از طریق JSX/COM و ذخیره‌ی خروجی
   (کاملاً دقیق، ولی نیازمند نصب فتوشاپ روی سیستم کاربر).
2. **خروجی CMYK / TIFF / PNG-24 با پروفایل رنگ** برای چاپ حرفه‌ای.
3. **پیش‌تنظیم‌های اندازه‌ی فیزیکی** (مثلاً ۹×۵ سانتی‌متر با ۳۰۰dpi).
4. **پیش‌نمایش زنده‌ی سریع‌تر** (کش رندر لایه‌های ثابت).
5. **بسته‌بندی مک/لینوکس** با همین spec (فقط `console=False` و مسیر آیکون تغییر می‌کند).
6. **امضای دیجیتال exe** برای حذف هشدار SmartScreen در ویندوز.

## ۵) قواعد کد

- پایتون ۳.۹+، بدون وابستگی سنگین جدید؛ فقط `numpy`، `pillow`، `openpyxl`، `psd-tools`.
- کامنت‌ها و پیام‌های کاربر **فارسی**؛ نام متغیرها و توابع **انگلیسی**.
- هیچ منطق تجاری داخل `web/app.js` نباشد جز نمایش/جمع‌آوری ورودی؛ محاسبات در `engine/`.
- هر تغییر در موتور، باید با `python tests/smoke_test.py` تست شود (و در صورت نیاز، بررسی
  جدیدی به همان فایل اضافه شود).
