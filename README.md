# تولید انبوه تصویر از قالب فتوشاپ

نرم‌افزاری ساده (وب‌اپ محلی) که یک **فایل فتوشاپ (PSD)** و یک **فایل اکسل** می‌گیرد و برای هر ردیف اکسل یک **تصویر خروجی (PNG/JPG)** می‌سازد؛ متن‌ها داخل قالب جایگزین می‌شوند، برای هر **شیت** یک پوشه با نام همان شیت ساخته می‌شود و **نام هر فایل** از ترکیب دو ستون دلخواه همان شیت ساخته می‌شود.

**رابط کاربری:** یک وب‌اپ محلی فارسی و راست‌چین با **تم روشن و تمیز** و **پنج تب پشت‌سرهم** — ۱) فایل‌ها ۲) لایه‌های متنی ۳) شیت‌ها و نام فایل ۴) تنظیمات ظاهری ۵) اجرا و خروجی. هر تب فقط کارهای همان مرحله را نشان می‌دهد و تب‌های بعدی بعد از «بررسی و بارگذاری فایل‌ها» فعال می‌شوند.

مناسب برای: کارت ویزیت، برچسب محصول، سربرگ، اینوویس، کارت پرسنلی، گواهی/تقدیرنامه، تگ قیمت و هر قالبی که متن‌هایش عوض می‌شود.

---

## ۱) پیش‌نیاز

فقط **پایتون ۳.۹ یا بالاتر** (در ویندوز هم نصب می‌شود). بقیه‌ی کتابخانه‌ها در اولین اجرا خودکار نصب می‌شوند.

- ویندوز: از [python.org](https://www.python.org/downloads/) نصب کنید و در ابتدای نصب تیک **Add python.exe to PATH** را بزنید.
- مک/لینوکس: `python3` معمولاً از قبل هست.

> برای انتخاب فایل/پوشه با پنجره‌ی سیستمی، ماژول `tkinter` لازم است (در ویندوز همراه پایتون نصب می‌شود؛ در لینوکس: `sudo apt install python3-tk`).
> اگر نبود هم مشکلی نیست — برنامه یک پنجره‌ی مرور مسیر داخلی نشان می‌دهد.

---

## ۲) اجرا

**ویندوز:** روی فایل `run.bat` دوبار کلیک کنید.

**مک/لینوکس:** در ترمینال داخل پوشه‌ی برنامه:

```bash
python3 run.py
```

یا:

```bash
pip install -r requirements.txt
python3 server.py            # سپس در مرورگر: http://127.0.0.1:8756
```

مرورگر خودکار باز می‌شود. برای بستن برنامه، همان پنجره‌ی ترمینال را ببندید.

گزینه‌های خط فرمان:

```bash
python3 run.py --port 9000            # تغییر پورت
python3 run.py --host 0.0.0.0         # در دسترس قرار دادن روی شبکه‌ی محلی
python3 run.py --no-browser           # بدون باز کردن مرورگر
```

## ۳) کار در ۵ تب

### تب ۱ — فایل‌های ورودی
فایل اکسل، فایل PSD و پوشه‌ی مقصد را انتخاب کنید (دکمه‌ی 📁 کنار هر کادر، مرورگر داخلی برنامه را باز می‌کند)؛ فرمت خروجی و سطر عنوان‌ها را هم مشخص کنید و «بررسی و بارگذاری فایل‌ها» را بزنید.
فرمت پیش‌فرض **PDF** است با حالت «**هر لیبل جدا + یک فایل کلی از همه‌ی لیبل‌ها**»؛ اگر PNG/JPG/WEBP می‌خواهید فقط از فهرست «فرمت خروجی» عوضش کنید.

### تب ۲ — لایه‌های متنی (پلیس‌هولدرها در فتوشاپ)
در فتوشاپ، داخل **متن لایه‌ها** هرجای متن که باید عوض شود، عنوان ستون اکسل را داخل آکولاد بنویسید:

```
{{نام و نام خانوادگی}}        →  سارا محمدی
{{سمت}}                        →  مدیر فروش
کد: {{کد محصول}}               →  کد: OL-1001
{{موبایل}} | {{ایمیل}}         →  ۰۹۱۲۳۴۵۶۷۸۹ | sara@arya.ir
```

نکته: متن لایه‌ها باید **لایه‌ی متنی (Type Layer)** فتوشاپ باشد، نه تصویر.

برنامه بعد از «بررسی» همه‌ی پلیس‌هولدرها را پیدا می‌کند و خودش آن‌ها را با ستون هم‌نامشان تطبیق می‌دهد (حساس به نیم‌فاصله/فاصله/ی و ک عربی نیست). اگر عنوانی پیدا نشد، از فهرست بازشو خودتان ستون درست را انتخاب کنید.

سه حالت برای هر لایه وجود دارد:

| حالت | کاربرد |
|---|---|
| **جایگزینی پلیس‌هولدر** | فقط بخش‌های `{{...}}` عوض می‌شوند، بقیه‌ی متن دست‌نخورده می‌ماند. |
| **کل متن = یک ستون** | تمام متن لایه با مقدار یک ستون اکسل جایگزین می‌شود. |
| **دست نزن** | این لایه بدون تغییر در همه‌ی خروجی‌ها می‌آید (مثلاً شعار ثابت). |

برای هر لایه می‌توانید **جهت متن** را هم تعیین کنید (`خودکار` / `راست‌به‌چپ` / `چپ‌به‌راست`)؛ مثلاً لایه‌ای که هم عدد فارسی و هم ایمیل لاتین دارد را روی «راست‌به‌چپ» بگذارید تا از لبه‌ی راست تراز شود.

#### قالب اختصاصی هر شیت 🆕
در تب ۳ برای هر شیت می‌توانید **قالب PSD متفاوتی** بدهید (مثلاً شیت «کارت محصول» با قالب کارت محصول و شیت «کارت ویزیت» با قالب کارت ویزیت). اگر ستون قالب را هم انتخاب کنید، **قالب هر ردیف** از همان ستون خوانده می‌شود (مثلاً ستون «نوع کارت» → `card-gold.psd` یا `card-silver.psd`). قالب‌ها با نام فایل یا مسیر کامل نوشته می‌شوند و در پوشه‌ی قالب پیش‌فرض جست‌وجو می‌شوند.

### تب ۳ — شیت‌ها و نام فایل
برای **هر شیت**:

- **ستون نام فایل ۱** و **ستون نام فایل ۲**: نام فایل از ترکیب این دو ساخته می‌شود (مثلاً `سارا محمدی-مدیر فروش.png`).
- **جداکننده**: هر کاراکتری که بخواهید (`-`، `_`، فاصله و…).
- **پیشوند/پسوند**: مثلاً `tarh-` یا `-1404`.
- **بازه‌ی ردیف‌ها**: از ردیف چندم تا چندم خوانده شود (برای تست یا تولید بخشی از لیست).
- **پوشه‌ی شیت**: اگر تیک باشد، داخل پوشه‌ی مقصد زیرپوشه‌ای با **نام دقیق همان شیت** ساخته می‌شود.

ساختار خروجی:

```
پوشه‌ی مقصد/
├── کارت ویزیت/           ← نام شیت اول
│   ├── سارا محمدی-مدیر فروش.png
│   └── علی رضایی-کارشناس بازاریابی.png
└── برچسب محصول/          ← نام شیت دوم
    ├── OL-1001_روغن زیتون فرابکر.png
    └── HO-2043_عسل طبیعی کوهستان.png
```

نام‌های تکراری خودکار شماره می‌خورند (`نام_2.png`) و کاراکترهای غیرمجاز ویندوز (`\ / : * ? " < > |`) با `-` عوض می‌شوند.

### تب ۴ — تنظیمات ظاهری

| گزینه | توضیح |
|---|---|
| **دقت خروجی (مقیاس)** | ۱۰۰٪ = اندازه‌ی خود سند. برای چاپ ۲۰۰٪ یا ۳۰۰٪. |
| **فونت جایگزین** | اگر فونت فارسی روی سیستم شما نیست، یکی از فونت‌های فارسی نصب‌شده را انتخاب کنید (یا با «افزودن فونت» فایل فونت را به برنامه بدهید). |
| **رنگ متن** | در صورت فعال‌بودن، رنگ همه‌ی متن‌ها به این رنگ درمی‌آید (مثلاً متن سفید روی کارت تیره). |
| **ضریب اندازه‌ی فونت / فاصله‌ی خطوط** | تنظیم دقیق برای وقتی متن بلندتر از قالب است. |
| **جابجایی افقی/عمودی** | جابجایی همه‌ی متن‌ها به پیکسل (وقتی فونت جانشین کمی متفاوت می‌نشیند). |
| **پس‌زمینه** | رنگ یا حالت شفاف (خروجی PNG شفاف). |
| **سوپرمپل** | ۲× یا ۳× برای لبه‌های نرم‌تر و کیفیت بیشتر. |

#### فرمت‌های خروجی

| فرمت | توضیح |
|---|---|
| **PNG / JPG / WEBP** | برای هر ردیف یک تصویر. |
| **PDF** | چهار حالت انتخابی (پایین‌تر) — پیش‌فرض: هر لیبل جدا + یک فایل کلی. |
| **CSV فهرست** | کنار خروجی‌ها یک فایل `_فهرست-خروجی.csv` با نام فایل‌ها و همه‌ی ستون‌ها ساخته می‌شود. |

#### حالت‌های PDF

| حالت (گزینه‌ی «حالت خروجی PDF») | خروجی |
|---|---|
| **هر لیبل جدا + یک فایل کلی از همه‌ی لیبل‌ها** *(پیش‌فرض)* | برای هر ردیف یک PDF تک‌صفحه‌ای داخل پوشه‌ی شیت + یک فایل یکپارچه از همه‌ی لیبل‌ها در پوشه‌ی مقصد |
| **فقط یک فایل کلی از همه‌ی لیبل‌ها** | تنها یک PDF یکپارچه (همه‌ی صفحه‌ها پشت‌سرهم) در پوشه‌ی مقصد |
| **در هر پوشه یک فایل یکپارچه** | در هر پوشه‌ی شیت، یک PDF شامل همه‌ی ردیف‌های همان شیت |
| **فقط هر لیبل جداگانه** | برای هر ردیف یک PDF تک‌صفحه‌ای و بدون فایل یکپارچه |

نام فایل یکپارچه را خودتان در کادر «نام فایل کلی PDF» می‌نویسید و رزولوشن با عدد dpi (پیش‌فرض ۱۵۰) تنظیم می‌شود.
خروجی نمونه با تنظیمات پیش‌فرض:

```
پوشه‌ی مقصد/
├── همه-صفحات.pdf            ← یک فایل کلی از همه‌ی لیبل‌ها (۷ صفحه)
├── کارت ویزیت/
│   ├── سارا محمدی-مدیر فروش.pdf      ← هر لیبل در یک فایل جدا
│   └── _فهرست-خروجی.csv
└── برچسب محصول/
    ├── روغن زیتون فرابکر-OL-1001.pdf
    └── _فهرست-خروجی.csv
```

### تب ۵ — اجرا و خروجی (پیش‌نمایش و تولید)
- **نمایش پیش‌نمایش**: خروجی یک ردیف مشخص را قبل از تولید کل لیست ببینید (همراه با فهرست جایگزینی‌های انجام‌شده).
- **شروع تولید**: کل عملیات اجرا می‌شود؛ درصد پیشرفت، فایل در حال ساخت، لاگ و خطاها هم‌زمان نمایش داده می‌شوند.
- **توقف**: هر زمان بخواهید عملیات متوقف می‌شود (فایل‌های ساخته‌شده باقی می‌مانند).
- **باز کردن پوشه‌ی خروجی**: پوشه‌ی مقصد را در ویندوز باز می‌کند.
- **ذخیره/بازخوانی تنظیمات**: کل تنظیمات (نگاشت ستون‌ها، فونت، ابعاد) در `settings.json` ذخیره می‌شود تا اجرای بعدی دوباره‌کاری نشود.

## ۳.۵) نسخه‌ی ویندوزی (exe) و ساخت با گیت‌هاب 🆕

می‌خواهید برنامه بدون پایتون و **بدون پنجره‌ی سیاه CMD** اجرا شود؟ سه راه:

| راه | چطور |
|---|---|
| **ساخت با گیت‌هاب (بدون نصب چیزی)** | پوشه را در یک ریپازیتوری گیت‌هاب بگذارید؛ ورک‌فلو `build-windows` خودش exe را می‌سازد و در تب **Actions → Artifacts** برای دانلود می‌گذارد. با `git tag v1.0.0 && git push origin v1.0.0` همان فایل در **Releases** منتشر می‌شود. |
| **ساخت روی ویندوز خودتان** | دوبار کلیک روی `packaging/build_windows.bat` → خروجی `dist\PSD-Batch-Generator\PSD-Batch-Generator.exe` |
| **اجرا از سورس بدون CMD** | دوبار کلیک روی `run_windows.bat` (برنامه با `pythonw` بالا می‌آید و پنجره‌ی کنسول بلافاصله بسته می‌شود) |

- **آیکون:** `packaging/icon.ico` روی خود فایل اجرایی و پنجره‌ی برنامه می‌نشیند (برای ساخت دوباره‌ی آیکون: `python3 packaging/make_icon.py`).
- **ماژولار:** نسخه‌ی پیش‌فرض یک پوشه است (`--onedir`): exe + کتابخانه‌ها + پوشه‌های `web/`، `fonts/` و `samples/`؛ می‌توانید رابط کاربری یا فونت‌ها را بدون ساخت دوباره عوض کنید. نسخه‌ی تک‌فایلی هم با `set PSD_BATCH_ONEFILE=1` ساخته می‌شود.
- **فایل‌های کاربر:** `settings.json` و `psd-batch.log` کنار برنامه ساخته می‌شوند (اگر آن پوشه قابل‌نوشتن نبود، در `%APPDATA%\PSD-Batch-Generator`).
- راهنمای کامل + عیب‌یابی: **`docs/BUILD-WINDOWS.md`** — برای برنامه‌نویسی که پروژه را تحویل می‌گیرد: **`docs/HANDOFF.md`** — خلاصه‌ی انگلیسی: **`docs/README.en.md`**
- **صفحه‌ی معرفی تک‌فایلی HTML:** با `python3 tools/make_landing.py` ساخته می‌شود (`docs/index.html`) — یک فایل خودبسنده با تصاویر جاسازی‌شده، قابل انتشار روی **GitHub Pages** (Settings → Pages → Folder: `/docs`). این فایل تولیدشده است و در مخزن نگه داشته نمی‌شود.

## ۴) فونت فارسی

۱. بهترین حالت: فونت فارسی روی ویندوز شما نصب باشد و در فتوشاپ هم همان فونت استفاده شده باشد
(مثل **وزیرمتن، ایران‌سنس، یکان، ساحل، شبنم**). برنامه فونت را از روی نامش در قالب پیدا می‌کند.

۲. اگر فونت قالب نصب نباشد، برنامه به‌طور خودکار یک فونت فارسی مناسب از سیستم انتخاب می‌کند و در بخش پیش‌نمایش هشدار می‌دهد.

۳. هر فایل فونتی (`.ttf` / `.otf` / `.ttc`) را می‌توانید در پوشه‌ی **`fonts`** کنار برنامه کپی کنید یا از دکمه‌ی «افزودن فونت» استفاده کنید؛ بعد از آن در فهرست فونت‌ها ظاهر می‌شود.

متن فارسی با موتور **HarfBuzz** (از طریق Pillow) شکل‌دهی می‌شود؛ یعنی حروف درست به هم می‌چسبند (چسبندگی حروف و راست‌چینی صحیح).

## ۵) محدودیت‌ها (صادقانه)

- لایه‌های **متنی** کامل بازسازی می‌شوند. افکت‌های لایه به‌صورت تقریبی بازسازی می‌شوند: **سایه‌ی بیرونی، خط دور (Stroke)، رنگ رویی، درخشش بیرونی**. افکت‌های پیچیده (Bevel، Pattern، Gradient Overlay، Satin، …) در خروجی اعمال **نمی‌شوند** و برنامه هشدار می‌دهد.
- نمای خروجی یک **رندر تقریبی** است؛ اگر دقتی میلی‌متری لازم دارید، در تب ۴ تیک «ذخیره‌ی PSD اصلاح‌شده» را هم بزنید تا کنار تصویر، فایل PSD با متن‌های درست ذخیره شود (برای بازبینی در خود فتوشاپ).
- اگر لایه‌ی متنی داخل **گروه (Group)** باشد مشکلی نیست و پشتیبانی می‌شود. لایه‌های **پنهان** در خروجی نمی‌آیند.
- Smart Objects، ماسک‌ها و تصاویر لایه‌ای همان‌طور که در فتوشاپ هستند با همان موتور ترکیب می‌شوند و مشکل ندارند.
- فایل‌های `.psb` (سند بزرگ) هم باز می‌شوند؛ برای ابعاد بزرگ، مقیاس ۱۰۰٪ را انتخاب کنید.

## ۶) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «لایه‌ی متنی پیدا نشد» | متن‌های قالب را با ابزار **Type** فتوشاپ نوشته باشید (نه تصویر یا Shape). |
| فونت فارسی به‌هم‌ریخته/جدا جدا | در تب ۴ یک فونت فارسی نصب‌شده را در کادر «فونت جایگزین» انتخاب کنید (یا فونت را در پوشه‌ی `fonts` بگذارید). |
| متن کمی جابجاست | از «جابجایی افقی/عمودی» و «ضریب اندازه‌ی فونت» استفاده کنید. |
| خروجی بزرگ/کند است | مقیاس ۱۰۰٪، سوپرمپل ۱× یا ۲×؛ از فرمت JPG به‌جای PNG استفاده کنید. |
| خطای فونت/نویسه‌ی ناشناس | فونت آن متن نویسه‌ها را ندارد؛ فونت دیگری انتخاب کنید. |
| مسیر فارسی خطا می‌دهد | مسیرهای فارسی/فاصله‌دار پشتیبانی می‌شوند؛ فقط مسیر را کامل و با درایو (مثل `D:\کار\طرح.psd`) وارد کنید. |
| مرورگر باز نشد | آدرس `http://127.0.0.1:8756` را دستی باز کنید. |

python3 tools/make_sample.py

## ۸.۵) چه چیزی در مخزن گیت‌هاب نیست (و چرا)

این‌ها **خروجی ابزارها** هستند و برای اجرا/ساخت برنامه لازم نیستند؛ در `.gitignore` هم آمده‌اند:

| مورد | توضیح |
|---|---|
| `preview/` | اسکرین‌شات‌ها و فایل‌های `app-preview.pdf/html`. ساخت دوباره: `python3 tools/capture_shots.py` سپس `python3 tools/make_preview.py` (نیازمند playwright) |
| `settings.json` | تنظیمات شخصی هر کاربر. نمونه‌اش در مخزن هست: `settings.example.json` |
| `psd-batch.log` | لاگ اجرای نسخه‌ی ویندوزی |
| `dist/`, `build/` | خروجی ساخت exe |
| `samples/خروجی-*/` | خروجی‌های نمونه که با اجرای برنامه ساخته می‌شوند |

> برای ساخت صفحه‌ی معرفی تک‌فایلی HTML (مناسب GitHub Pages) کافی است اول اسکرین‌شات‌ها را بگیرید و بعد `python3 tools/make_landing.py` را اجرا کنید؛ فایل `docs/index.html` ساخته می‌شود.
